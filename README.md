# 闲兔H3全功能导演台V1

一个画布节点集成漫剧/短剧、角色替换、H3-IMAGE 做图和数字人 V2 四个工作台。目录名为 `ComfyUI-Full-Director`，包标识为 `comfyui-full-director`。

四套工作台复制到插件内部，各自保留原有主题、控件与排版，通过同一套左侧导航切换。顶部栏和底部时间线/结果区保持全宽。导航顺序为文生视频、图生视频、首尾帧、多参考生视频、角色替换、H3-IMAGE 做图、数字人。素材绑定、提示词、分镜、优化设置、任务状态和结果分别保存。H3-IMAGE 页面使用 H3-IMAGE 接口，不进入 P-H3 分支。

四个页面使用同一个公共资产库，数字人入口位于参考图面板底部。原数字人项目资产、生图旧资产会复制归入公共库，原文件保留；应用图片时仍绑定到各自页面的当前分镜。生图移除左侧优化模型配置入口，保留右侧提示词优化及画布的优化模型输入。

## 接线

在画布添加“闲兔H3全功能导演台V1”。原漫剧 CLIP、VAE、音频 VAE 接口保留，另加三套专用模型接口。

| 页面 | 模型输入 | 对应输出 |
| --- | --- | --- |
| 漫剧/短剧 | CLIP、VAE、音频 VAE | 条件、Latent、放大前文件名、放大后文件名 |
| 角色替换 | 角色替换_CLIP、角色替换_VAE、角色替换_音频VAE | 条件、Latent、原声、引导视频帧、分镜帧数、文件名 |
| H3-IMAGE | H3_IMAGE_CLIP、H3_IMAGE_VAE、H3_IMAGE_提示词优化模型 | 条件、Latent、文件名 |
| 数字人 V2 | 数字人_H3_CLIP、数字人_H3_VIDEO_VAE、数字人_H3_AUDIO_VAE | H3条件、H3 Latent、H3图像、H3音频、H3放大前文件名、H3放大后文件名 |

共 12 个模型输入和 19 个输出。原有前 13 个输出编号保持不变，数字人追加在其后。将原工作流的采样、解码、保存分支分别接到对应输出。角色替换参考条件仍支持 `video_audio`、`guide` 和 `pose`；沿用 Add Guide 时选择 `guide`。H3-IMAGE 优化模型仅在该页开启优化时参与执行。数字人 V2 完整保留原版分镜管理、音轨编辑、参考图、资产库、提示词、批量生成、结果管理和导出界面。原音频编码进音视频潜空间并固定音频流。项目数据使用本插件独立的项目目录和服务端点；可选提示词优化使用本插件独立运行时，不调用第三方提示词插件。

工作台提交时生成当前页面的执行副本，调整该分支的端口编号并排除另外三页的下游分支。支持把原导演台内部辅助节点映射到本插件自带副本，不改写用户画布上的原节点类型。

## 独立性

代码、前端资源、服务接口、运行状态和本地提示词优化运行库都位于本目录。不导入原漫剧导演台、动作迁移导演台、H3生图工作台或闲兔助手。角色多视图组件也已内置。

ComfyUI 核心、模型文件以及画布使用的采样/放大等社区节点仍按四类工作流原有要求准备。插件不包含模型。默认输出分别归档到 `全功能导演台/漫剧短剧`、`全功能导演台/角色替换` 、`全功能导演台/H3image生图` 和 `全功能导演台/数字人`。

安装后重启 ComfyUI 并刷新前端。当前版本：`0.1.1`。仓库和更新地址见 [GitHub](https://github.com/xiantuhenlan/ComfyUI-Full-Director)。
